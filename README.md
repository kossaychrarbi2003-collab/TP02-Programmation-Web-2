  ## Exercice 2 — Variables

PHP est sensible à la casse : `$note` et `$Note` sont deux variables différentes.

### Noms de variables valides

- `$a` : valide
- `$_a` : valide
- `$a_a` : valide
- `$AAA` : valide
- `$a!` : invalide
- `$1a` : invalide
- `$a1` : valide
